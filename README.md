KAIP PALEISTI PROJEKTĄ.

1. Parašyk "npm i" "api" ir "frontend" aplankose.
2. Sukurkite failo ".env.example" kopiją ir pervardykite ją į ".env" tiek "api", tiek "frontend" aplankuose.
3. Paleiskite API serverį naudodami "node server.js", o frontend – "npm run dev"
4. Įkelkite duomenis į "MongoDB Compass"; duomenis rasite aplanke "Data"
5. Štai ir viskas!
